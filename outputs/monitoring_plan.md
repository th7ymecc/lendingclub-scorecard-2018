# LendingClub 2012–2018 评分卡 · 上线后监控方案（v3）

> 本方案在 v2 的 **MOB12 固定窗口 + 终身 PD 换算** 基础上，修正了阈值敏感性加权标签的 `int` 截断，统一了终身坏账率口径（E[y/e] = 18.97%），并补充了打分产物口径。v2 方案归档为 `outputs/monitoring_plan_v2_mob12.md`。
>
> 数据快照：2019-03-31；OOT：2017-01 ~ 2018-03（2018Q2+ 观察不足 12 个月，不进入 MOB12 OOT）。生产阈值 0.27 是**终身 PD**；打分脚本输出 `prob_lifetime` 与 `approve`，不要拿未校准的 MOB12 PD 直接套 0.27。

## 1. 监控原则

- **口径优先**：任何坏账率必须同时标注“MOB12 vintage”还是“终身加权”；两者不可直接比较。
- **分层监控**：数据质量 → 分数分布 → 区分能力 → 资产质量，逐层递进。
- **先归因、后动作**：PSI 报警不等于模型失效，必须先区分数据问题、客群变化、策略变化与真实风险恶化。
- **成熟度优先**：AUC/KS 与坏账率只在观察满 12 个月的 vintage 上评估，避免 2018Q2+ 的未成熟样本。
- **阈值可审计**：所有阈值调整、模型变更均记录时间、原因、审批人与影响评估。

## 2. PSI 监控阈值

| PSI | 等级 | 动作 |
|---|---|---|
| < 0.10 | 绿色 / 稳定 | 正常监控 |
| 0.10–0.25 | 黄色 / 关注 | 2 个工作日内归因；评估收紧阈值 |
| > 0.25 | 红色 / 预警 | 1 个工作日内升级；暂停自动审批/人工复核；准备重训或回滚 |

补充规则：

- 评分 PSI 连续 2 个月黄色，升级为红色管理。
- 单特征 PSI > 0.25 且对评分贡献较大（IV/系数前 10），优先排查该特征口径与渠道。
- 本项目 OOT 特征 PSI 最高为 `bc_open_to_buy` 约 0.101（黄色边缘）；评分 PSI 0.0503，绿色。
- 2018Q4 不进入 MOB12 OOT（标签不成熟）；PSI 用全量申请样本计算，可以看，但不要把它与“成熟 cohort 的坏账率”混为一谈。

## 3. 监控指标矩阵

| 指标 | 频率 | 预警阈值 | 业务含义 |
|---|---|---|---|
| 数据质量（缺失/延迟/渠道） | 日 | 任一字段缺失率偏移 >5pp | 先排除数据链路问题 |
| Score PSI | 月度 | <0.10 绿；0.10–0.25 黄；>0.25 红 | 分数分布漂移 |
| 特征 PSI（Top 10） | 月度 | 单特征 >0.25 | 定位漂移来源 |
| OOT AUC（MOB12） | 季度（成熟 vintage） | 较基线下降 >0.02 关注，>0.03 预警 | 区分能力 |
| OOT KS（MOB12） | 季度（成熟 vintage） | 较基线下降 >0.03 关注，>0.05 预警 | 排序能力 |
| 批准率 | 日/周 | 较基线偏移 ±5pp | 策略或客群变化 |
| 批准人群 MOB12 vintage 坏账率 | 月度/季度 | 较基线相对上升 >15% 关注，>25% 预警 | 可观测的早期资产质量 |
| 批准人群**估算终身**坏账率 | 月度（用 e 估算） | 较基线相对上升 >15% 关注，>25% 预警 | 决策口径的滚动估计 |
| 实际终身坏账率 | 季度（仅成熟 cohort） | 与估算值偏差 >5pp | 校准/外推校验 |
| 校准（平均 PD vs 实际） | 月度（MOB12）/季度（终身） | 终身 PD − 实际 >5pp 或斜率明显偏离 | 绝对风险/定价 |
| Vintage 坏账率（MOB12） | 季度 | 同账龄连续 2 个 cohort 恶化 | 客群/宏观/策略变化 |
| 拒绝率/人工复核率 | 日 | 较策略基线偏移 ±5pp | 审批策略或模型异常 |

## 4. 预警流程

1. **T+0 自动检测**（监控工程师）：数据质量、Score PSI、批准率、缺失率；红色自动告警到风控模型群。
2. **T+0~T+1 分级响应**（模型负责人）：黄色 2 个工作日内归因；红色 1 个工作日内组织临时风险会，必要时收紧 cutoff / 人工复核。
3. **T+1~T+3 归因**（模型 + 策略）：按渠道、客群、分数段、特征 PSI 拆解；核对数据口径、进件政策、宏观/季节性；输出归因报告。
4. **T+3~T+10 处置**（风险委员会）：维持观察 / 截距校准 / 收紧阈值 / 重新分箱 / 重训 / 回滚；所有变更审批留痕。
5. **月度复盘**（模型委员会）：AUC/KS、PSI、Vintage、批准率、坏账率、校准与策略收益；更新监控基线。

### 升级与降级

- 黄色预警连续 2 个周期未收敛 → 升级红色。
- 红色预警完成归因且指标恢复 → 降级黄色观察 1 个月，再回绿色。
- 任何阈值调整、重训、回滚都必须经过模型委员会审批并保留变更记录。

## 5. 假设性报警案例

### 案例 A：某月 Score PSI 突升到 0.32

**触发信号：** 月度 Score PSI 从 0.03 升到 0.32（红色）；批准率同期从 77% 降到 70%。

**排查顺序：**

1. 先查数据：进件量、字段缺失率、T+1 延迟、渠道占比是否突变；确认不是数据链路问题。
2. 拆分数分布：按渠道/产品/客群看 score 均值、P25/P50/P75 与拒绝率，判断漂移来自哪一段。
3. 拆特征 PSI：取 Top 10 特征 PSI，检查是否由单一特征（如 `bc_open_to_buy`、`term`、`loan_income_ratio`）贡献 >50%。
4. 对齐业务事件：新渠道上线、客群准入政策、额度/定价调整、宏观冲击或季节性。
5. 验证影响：在最近成熟 MOB12 vintage 上重算 AUC/KS、分数段**终身**坏账率、批准坏账率与校准斜率。

**处置建议：**

- 数据问题：修复链路并暂停自动审批。
- 真实客群漂移但排序尚可：收紧 cutoff/人工复核，评估截距校准。
- AUC/KS 明显下降：启动重训或回滚。

### 案例 B：PSI 仅 0.08，但批准坏账率升到 18%

**触发信号：** Score PSI 绿色（0.08），但批准人群**终身**坏账率 18%，高于 15% 目标；平均终身 PD 仅 16%。

**排查顺序：**

1. 先做校准检查：按终身 PD 分箱对比平均预测 PD 与实际坏账率，拟合校准斜率/截距，确认是否整体低估。
2. 检查客群/账龄结构：2018 类早成熟 cohort 占比是否上升；坏账率是否被“更早核销”的样本结构放大。
3. 查策略与定价：审批阈值、额度、利率、渠道组合是否变化；是否存在风险更高的新客群。
4. 对照 Vintage：同账龄 cohort 的坏账率是否连续恶化；是宏观/客群问题还是模型失效。
5. 在验证集上重算目标阈值：若只是校准偏移，优先截距校准/收紧阈值；若排序下降，再考虑重训。

**处置建议：** 不要因为 PSI 绿色就忽略校准报警。先收紧阈值/人工复核并做截距校准；连续 2 个月恶化则启动重训。

## 6. 处置动作库

| 场景 | 首选动作 | 备选动作 |
|---|---|---|
| 数据口径/缺失异常 | 修复数据链路，暂停自动审批 | 临时规则兜底 |
| 客群结构变化但排序能力尚可 | 调整截距/分数校准 | 分客群阈值 |
| PSI 高且 AUC/KS 明显下降 | 重新分箱/重训 | 回滚上一版本 |
| 资产质量恶化但模型区分度正常 | 收紧 cutoff、提高人工复核比例 | 调整授信额度/定价 |
| 宏观/政策冲击 | 临时风险策略、压力测试 | 暂停新增、限额管理 |

## 7. 重训触发条件

满足任一条件即启动重训评估：

1. 评分 PSI > 0.25 连续 2 个月，或单月 > 0.40。
2. OOT AUC（MOB12）较基线下降 > 0.03，或 KS 下降 > 0.05。
3. 同账龄 MOB12 vintage 坏账率连续 2 个 cohort 相对恶化 > 25%。
4. 批准率或拒绝率相对基线偏移 > 10pp，且无法用策略调整解释。
5. 关键特征口径、数据源、进件政策发生重大变化。
6. 监管/合规要求或模型有效期到期（建议至少每年独立验证一次）。

## 10. 打分产物口径（v3）

`python scripts/score_csv.py --input ... --output ...` 现在加载 `outputs/decision_policy.json`，输出：

| 列 | 含义 |
|---|---|
| `score` | 整数评分卡分数（保留用于原因码/审计） |
| `prob_mob12_raw` | 未校准的 MOB12 PD（建模输出） |
| `prob_mob12_calibrated` | Platt 校准后的 MOB12 PD |
| `prob_lifetime` | 按 `e(term)` 换算后的终身 PD（业务决策口径） |
| `grade` | 按终身 PD 的 A–E：A<8%、B 8–12%、C 12–18%、D 18–25%、E≥25% |
| `approve` | `prob_lifetime < 0.27` |
| `term_num` / `emergence_frac` / `lifetime_clipped` | 终身换算的审计字段 |

> 注意：`scorecard.json` 里的 `grade_cutoffs` 是按 MOB12 PD 推出的分数切点，属于旧口径展示；生产等级以 `decision_policy.json` 的终身 PD 切点为准。
